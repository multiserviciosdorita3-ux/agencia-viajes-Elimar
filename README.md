# 🌍 Agencia de Viajes Elimar

Sitio web moderno y responsive para una agencia de viajes.
Incluye paquetes turísticos con precios, destinos, servicios y contacto directo por WhatsApp.

---

## 🚀 Características

* Diseño responsive (móvil, tablet y PC)
* Sección de paquetes con precios 💰
* Destinos con imágenes 🌎
* Servicios de la agencia 📋
* Botón de WhatsApp con mensaje automático 📲
* Animaciones al hacer scroll ✨
* Menú adaptable para móviles
* Datos separados en `data.js`

---

## 🛠️ Tecnologías

* HTML5
* CSS3
* JavaScript (Vanilla)
